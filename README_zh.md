# MosaicAgent-DD：学生操作入口

[English README](README.md)

当前文章只做**扫描、拼接、层数识别与统计、光谱资料核对**。第03项的颜色表示单层、双层和厚层。把相连三角分别圈成对象的“实例标注”属于另一项工作，其原工具和历史数据单独保留。

**[下载完整学生试跑包](https://github.com/YongXie-ICMM/MosaicAgent-DD/releases/latest)**：选 `MosaicAgent-DD-student-complete.zip`，里面包含程序、两张当前1920 × 1080原图、真实权重和启动文件。GitHub自动生成的Source code ZIP不包含大文件。

## 拿到完整试跑包之后

1. 把整个压缩包解压到一个可写文件夹。不要只取出其中一个 Python 文件。
2. 双击 **01_install**：首次安装环境。需要 Python 3.10 以上和联网下载依赖；窗口结束前不要关闭。
3. 双击 **02_run_layer_demo**：程序先核对原图和权重，再预测两个1920 × 1080示例；出现结果路径后再关闭窗口。
4. 双击 **03_open_workbench**：进入统一工作台，打开 **03 / 层数分析**，对照原图与预测图检查。默认不显示 overlay。

Windows 使用 `.bat`；macOS 使用 `.command`。每次预测放在新的 `outputs/demo/` 子文件夹，原图、权重和上次结果不覆盖。完整包使用相对位置；电脑用户名改变不需要手动重写路径。实际显微镜采集仍在 Windows 仪器电脑上运行。

**完整包必须包含：** `data/demo/source_images.zip`、`data/demo/assets.json`、`weights/model_0409_all.pth`。如果看到“缺少资源”，说明拿到的是仅含代码的 GitHub 包；请使用老师提供的完整学生包，不要随意下载名字相近的权重。下载代码不等于已经拿到实验数据。

**当前试跑结论：程序能运行，但旧0409权重在这两张新图上有明显错分（大片疑似衬底被分为单层）。这版用于检查流程和反馈问题，输出比例不能直接用于论文统计。先确认样品衬底、采集条件和适配权重，不需要学生修改算法。**

## 学生这次要交什么

- 保存新运行产生的结果目录和运行记录；不要修改原图或权重。
- 核对两个示例中原图与预测图是否一一对应，截图指出明显错分的位置。
- 记录安装是否成功、预测是否结束、报错原文和所用电脑系统。
- 暂不做晶畴分割、不做转角判断、不根据预测颜色直接判定2H/3R。

## 换成新扫描数据

先使用 **02 / 图像与拼接 → 检查新扫描图片与拼接设置**。选择本次原始采集文件夹，同时保留 `session.json` 和 `events.jsonl`。核对实际图片像素、相邻视野重叠及采集设置后，使用生成的拼接命令。不要用文件大小4 MB/2 MB推断位移应缩小一半。

新相机模式、物镜或步长要先完成小范围上机验证。采集安装及恢复方法见[采集说明](acquisition/README.md)。现有本机实验目录继续使用原路径；可通过工作台“连接工具”选择，不会搬走数据。
