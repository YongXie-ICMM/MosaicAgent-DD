05 / 人工复核

先看图，再做层数分析

核对色带、接缝和完整扫描范围。

放大检查原图与拼接结果，特别是色差曾出现的列、样品边缘与稀疏区域。

  • 扫描范围内的照片是否全部保留，边缘有没有缺口。
  • 相邻照片是否连续，列与列之间是否仍有明显色带。
  • 原图、校色记录和拼接输出是否对应同一批次。
