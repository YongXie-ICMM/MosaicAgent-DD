# 学生操作说明

MosaicAgent-DD 学生包 · 2026-10-05 版 · 照着做就行

> 这本说明只讲"怎么做"。遇到说明里没有的情况，把屏幕拍下来发给老师，不要自己改程序。
> PDF 版在学生包最外层：`00_STUDENT_GUIDE_zh.pdf`。

## 一页速查

**分析电脑（任何 Windows / macOS 电脑）**

1. 把整个学生包解压到一个文件夹。
2. 双击 `01_install`（只在第一次做）。
3. 双击 `02_run_layer_demo`，等它跑完。
4. 双击 `03_open_workbench`，看原图和预测图。

**仪器电脑（接显微镜的 Windows 电脑）**

1. 第一次：双击 `acquisition\Auto_Scan\01_setup.bat`。
2. 每个扫描日：双击 `acquisition\Auto_Scan\00_white_balance_then_scan.bat`。先对准一块干净的裸衬底做白平衡，再按 `Y` 开始扫描。

**三个"不要"**

- 不要改程序里的任何文件，不要换权重，不要在网上下载名字相近的权重。
- 做完白平衡后，不要再碰灯光、曝光、白平衡。
- 不要同时开两个扫描程序。

## 第一部分　分析电脑

### 1. 解压

把整个压缩包解压到一个自己能写入的文件夹，例如 `D:\MosaicAgent-DD` 或 `~/MosaicAgent-DD`。
解压后文件夹里应该有这些东西：

| 文件 / 文件夹 | 是什么 |
|---|---|
| `01_install.bat`、`.command` | 第一次安装用 |
| `02_run_layer_demo.bat`、`.command` | 跑层数识别 |
| `03_open_workbench.bat`、`.command` | 看结果 |
| `data\demo\source_images.zip` | 两张原图 |
| `weights\model_0409_all.pth` | 模型权重（34 MB） |
| `00_STUDENT_GUIDE_zh.pdf` | 本说明 |

少了 `data` 或 `weights` 文件夹，说明拿到的不是学生包。找老师要完整的包。

### 2. 第一次：安装（双击 `01_install`）

- Windows 双击 `01_install.bat`；macOS 双击 `01_install.command`。
- macOS 如果提示"无法验证开发者"，在文件上点右键 → 打开。
- 电脑要先装好 Python 3.10 或更新版本，并且能上网。
- 黑窗口会自己下载安装，可能要几分钟。看到 `Ready.` 再关窗口。
- 装失败：把窗口里的文字截图发给老师。不要反复重装。

### 3. 每次：跑层数识别（双击 `02_run_layer_demo`）

程序先检查原图和权重有没有被改动，再对两张原图做层数识别。普通笔记本大约 1 到 3 分钟，不要中途关窗口。

结束时窗口会显示几行字，看懂这三行就够了：

| 屏幕上显示 | 意思 |
|---|---|
| `Results / 结果目录: outputs/demo/2026…` | 这次的结果放在这个文件夹。每次都新建文件夹，以前的结果不会被覆盖 |
| `Colour check / 颜色检查: …` | 颜色检查的结果，见第 5 条 |
| `Software completed; model applicability not validated` | 正常提示。意思是"程序跑完了，但这些数字不能直接写进论文" |

### 4. 看结果（双击 `03_open_workbench`）

浏览器会打开一个页面。点 **03 / 层数分析**。左边是原图，右边是预测图，一张对一张地看。
图上不同颜色表示单层、双层、厚层，颜色说明就在页面上。

如果页面上方的提示框里写着"颜色/白平衡与参考衬底颜色不一致"，说明这批图需要老师复核，看第 5 条。

### 5. 颜色检查是什么意思

程序会在原图里找一块**干净的裸衬底**，量它的颜色，和标准颜色 **R 219、G 171、B 170** 比。
如果差得超过 5%，模型就会"看错"：会把大片衬底当成单层。这不是你的错，是拍照时相机的白平衡变了。

| 屏幕上显示 | 意思 | 你要做的 |
|---|---|---|
| 没有颜色提示 | 颜色正常 | 正常看结果 |
| `颜色/白平衡与参考衬底颜色不一致` | 图偏蓝、绿色不够 | 结果只能看、不能用。下次拍照前先做白平衡（第二部分） |
| `implausible_gain_check_inputs` | 图太暗、太亮，或者根本不是显微镜图 | 检查图选对了没有、曝光正常不正常 |

**不要**为了让提示消失去改权重、改程序、改参考颜色，或者换别的模型。改了结果就没法追溯了。

### 6. 这次要交给老师的东西

1. `outputs\demo\` 里这次新建的整个文件夹。
2. 原图和预测图对比的截图，圈出明显判错的地方。
3. 一句话：安装成功没有，程序跑完没有，报错原文是什么，用的什么电脑系统。

## 第二部分　仪器电脑（扫描日）

### 7. 只做一次：安装

1. 仪器电脑是 Windows，装 64 位 Python 3.10 或更新版本。安装 Python 时勾选 **tcl/tk**。
2. 位移台和相机的驱动由老师或工程师安装。
3. 把整个学生包解压到仪器电脑上。`acquisition\Auto_Scan` 文件夹要完整。
4. 双击 `acquisition\Auto_Scan\01_setup.bat`。
5. 用 XIMC 位移台的话，老师会把 `libximc.dll` 放进 `Auto_Scan\drivers\`。

### 8. 每个扫描日：双击 `acquisition\Auto_Scan\00_white_balance_then_scan.bat`

扫描日**只从这一个文件进**。它先帮你把相机的白平衡调回标准颜色，再打开扫描程序。扫描程序本身和以前完全一样。

**第 1 步　白平衡**

1. 打开显微镜的灯，调到平时用的亮度。**记下亮度刻度**。
2. 把样品上一块**干净的裸衬底**移到画面正中间：没有晶体、没有灰尘、没有边缘、没有划痕。整个画面都是衬底。对好焦。
3. 回到黑窗口，按任意键。程序会自己连相机、关掉自动白平衡和自动曝光，然后一行一行打印读数，像这样：
   `R 217.0->219.2 (-1.0%)  G 156.0->170.9 (-8.7%)  B 181.0->170.0 (+6.5%)`
   意思是：现在读到的 R 是 217，标准是 219，差 −1%……三个数都在 ±5% 以内就算好了。
4. 看程序**最后一行**说什么：

| 程序最后说 | 意思 | 你要做的 |
|---|---|---|
| `白平衡已回到参考：保持灯光、曝光、白平衡不动，开始扫描` | 自动调好了，也记录好了 | 按 `Y` 开始扫描。从现在起不要再碰灯光、曝光、白平衡 |
| `此采集路径没有可写的曝光和白平衡控制`，同时弹出一个带读数的小窗口 | 这台相机电脑调不了，要在**相机自己的菜单**里调 | 一边看小窗口的读数和提示（Too blue = 偏蓝，Not enough green = 绿不够，Too dark = 太暗），一边在相机菜单里调色温、色调、曝光。三个数都进 ±5%、第一行变绿后，按键盘 `a` 记录。实在调不进去，按 `f` 先记录下来，然后告诉老师 |
| `视野不是干净裸衬底，拒绝记录`，或读数行里有 `NOT clean` | 画面里有晶体、灰尘、边缘，或者没对焦 | 换一块更干净的衬底位置，重新双击运行 |
| `已记录但未达到参考` | 调不到 ±5% 以内 | 可以继续扫描，但分析时会被标成"待复核"。把当天的记录文件夹交给老师 |

程序会问你**灯光亮度刻度**和**物镜倍数**，照实填，然后回车。
记录自动保存在 `acquisition\Auto_Scan\colour_calibration\` 里，不用你管。

**第 2 步　扫描**

程序问 `Start the scanner now [Y,N]?`，按 `Y`。后面和以前一样：

1. 在扫描程序里点连接相机，确认画面是显微镜画面，大小是 1920 × 1080。
2. 第一次先扫 **3 × 3** 的小范围，用分步确认模式。看相邻两张图有没有重叠部分、清不清楚。
3. 扫完点停止、断开，再关程序。不要同时开第二个扫描程序。
4. 扫描结果文件夹里的 `session.json`、`events.jsonl` 和所有原图都要留着，不要删、不要改名。

中途如果动了灯光、曝光或白平衡，这次扫描作废，重新从 `00_white_balance_then_scan.bat` 开始。

### 9. 扫完要交给老师的东西

1. 整个扫描结果文件夹（原图 + `session.json` + `events.jsonl`）。
2. `acquisition\Auto_Scan\colour_calibration\` 里当天的那个文件夹。
3. `acquisition\Auto_Scan\history\console_logs\` 里当天的文件。
4. 一句话：用的物镜、灯光刻度、相机菜单里改了什么。

## 第三部分　新扫描的图怎么分析

1. 在分析电脑上双击 `03_open_workbench`，点 **02 / 图像与拼接**，再点"检查新扫描图片与拼接设置"，选中扫描结果文件夹。
2. 按页面的提示一步步确认图片大小、重叠、采集设置，页面会生成拼接命令。
3. 后面的层数识别和颜色检查和第一部分一样。颜色提示没有了，说明白平衡做对了；还有提示，就把 `colour_calibration` 里的记录和这批图一起交给老师。

## 常见问题

| 遇到的情况 | 怎么办 |
|---|---|
| 双击 `.bat` 窗口一闪就没了 | 在那个文件夹里打开命令行窗口，手动输入文件名运行，把报错截图 |
| 提示 `Run 01_install.bat first` | 先双击 `01_install` |
| 提示缺少资源、校验失败 | 包不完整，或者文件被改过。重新解压完整的学生包 |
| 窗口里的中文是乱码 | 在命令行先输入 `chcp 65001` 回车，再运行；或者看英文那一半 |
| `02_run_layer_demo` 很慢 | 用 CPU 算，1 到 5 分钟是正常的。不要关窗口 |
| 白平衡程序说 `Camera opened but delivered no frame` | 相机被别的软件占着。关掉相机厂家的预览软件再试 |
| 白平衡程序说 `图像尺寸不一致：要求 [1920, 1080]` | 相机输出不是 1920 × 1080。在相机或驱动里改回来，不要让程序缩放 |
| 想先在没有相机的电脑上试试白平衡程序 | 在 `acquisition\Auto_Scan` 里运行 `python wb_calibrate.py --auto --simulate-camera`，用模拟画面自测。这种记录会放在 `simulation` 子文件夹，不会被当成真的 |

想了解为什么会有颜色问题，看 `docs\diagnostics\20261005_colour_balance\README.md`（英文）。
